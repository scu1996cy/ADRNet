# Attention-enhanced Dual-stream Registration Network via Mixed Attention Transformer and Gated Adaptive Fusion

This is the official pytorch implementation of the paper 'Attention-enhanced Dual-stream Registration Network via Mixed Attention Transformer and Gated Adaptive Fusion,' published in the Medical Image Analysis. [Paper](https://www.sciencedirect.com/science/article/abs/pii/S1361841525002609)

---

# Dataset

Experiments are conducted on four publicly brain MRI datasets: [Mindboggle](https://osf.io/nhtur/), [LONI Probabilistic Brain Atlas (LPBA)](https://resource.loni.usc.edu/resources/atlases-downloads/),  and [Open Access Series of Imaging Studies (OASIS)](https://sites.wustl.edu/oasisbrains/]).
